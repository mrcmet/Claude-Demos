# Claude-Demos

Welcome! This is a collection of demo projects used in Claude presentations. Whether you're brand new to coding or just getting started with AI tools, this guide will walk you through everything you need to get these files onto your computer and start exploring with [Claude Code](https://claude.ai/code).

---

## 📁 What's in This Repo?

| Folder / File | What it is |
|---|---|
| `Demo Project 1/` | A C program (`heartbeat_led.c`) that makes an LED pulse like a heartbeat on a Texas Instruments MSP430 microcontroller. |
| `Demo Project 2/` | An interactive spring-mass-damper physics simulation rendered in the browser (`spring_mass_damper.html`), plus style guides for a retro early-2000s web aesthetic. |
| `Class_Tracker_Fork/` | A web-based class/schedule tracker built with TypeScript and Vite. |
| `Claude Code Welcome.pptx` | A presentation slide deck introducing Claude Code. |

---

## ⬇️ How to Download These Files (No Git Required!)

You don't need Git or any special tools installed. Just follow these steps:

1. **Go to the top of this page** on GitHub (you're probably already there!).
2. Click the green **`<> Code`** button near the top-right of the file list.
3. In the dropdown menu, click **"Download ZIP"**.
4. A `.zip` file will be saved to your computer (usually in your `Downloads` folder).
5. **Unzip the file** by double-clicking it (Mac) or right-clicking and choosing "Extract All" (Windows).
6. You now have all the files on your computer! Open the folder and start exploring.

> 💡 **Tip:** If you want to open just a single file, you can also click on it in the GitHub file list and then click the download icon (⬇) in the top-right corner of the file viewer.

## 🤖 Getting Started with Claude Code

Once you have the files open in Claude Code (or any AI coding assistant), here are some **starter prompts** you can use to explore each project:

### 🔍 Understanding a Project
- *"What does this project do?"*
- *"Can you give me a plain-English summary of what this code does?"*
- *"Who would use this, and why?"*
- *"What problem is this code trying to solve?"*

### ▶️ Running a Project
- *"How do I run this program on my computer?"*
- *"What software or tools do I need to install before I can run this?"*
- *"Walk me through the steps to get this working from scratch."*
- *"Are there any dependencies I need to install first?"*

### 🧩 Understanding the Code
- *"Explain this code to me like I'm a beginner."*
- *"What does this function do?"* (highlight the function first)
- *"Why is this variable named this way?"*
- *"What happens step-by-step when this program runs?"*

### ✏️ Modifying the Code
- *"How would I change the LED blink speed in `heartbeat_led.c`?"*
- *"How can I add a new feature to this project?"*
- *"What would break if I changed this value?"*
- *"Can you help me add comments to explain what this code does?"*

### 🐛 Debugging & Troubleshooting
- *"I got this error message — what does it mean and how do I fix it?"*
- *"Why isn't this working the way I expected?"*
- *"Can you spot any bugs in this code?"*

### 📚 Learning More
- *"What coding concepts should I learn to better understand this project?"*
- *"Can you recommend any resources for learning more about [topic]?"*
- *"What's the difference between [concept A] and [concept B] in this code?"*
