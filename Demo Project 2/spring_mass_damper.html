» Transfer Function — 2nd Order System

Physical Form:

X(s) / F(s) =    1                            ms² + cs + k

where m = mass [kg], c = damping [N·s/m], k = stiffness [N/m]

  

Standard Form:

X(s) / F(s) =    (1/m)                                        s² + 2ζωₙs + ωₙ²

where ζ = damping ratio, ωₙ = natural frequency [rad/s]
Key Relations: ωₙ = √(k/m)    |    ζ = c / (2√(mk))    |    τ = 1 / (ζωₙ)    |    ω⁤ = ωₙ√(1 − ζ²)

Impulse Response h(t) by Damping Regime:

Underdamped (ζ < 1):
x(t) = exp(−ζωₙt)
      × sin(ω⁤t) / (mω⁤) 		Critically Damped (ζ = 1):
x(t) = (t/m)
      × exp(−ωₙt) 		Overdamped (ζ > 1):
x(t) = exp(−ζωₙt)
      × sinh(ωₕt) / (mωₕ)
